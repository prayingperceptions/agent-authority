# One-Minute Demo

## The hook

> What is your AI agent actually allowed to do?

## Demo

1. Create a Passport.
2. Create a Contract allowing GitHub read and requiring approval for email send.
3. Check GitHub read → `allow`.
4. Check email send → `ask`.
5. Check payments transfer → `deny`.
6. Approve the email action.
7. Show the signed Approval Receipt.
8. Run the same action in AgentBox.
9. Show the Ledger evidence bundle.

## Closing

> Your agent should not get a master key. Give it a Passport, a Contract, a Gate, and a receipt.
