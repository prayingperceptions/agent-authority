# Monetization

Keep the core protocol open and useful. Charge for operational complexity around the protocol.

## Free/open

- Passport
- Contract
- Gate
- Authority Score
- Approval primitives
- Local evidence
- Core SDK

## Paid services

### Agent hardening review

Indicative starting point: $99–$199 for an automated report plus remediation guidance.

### Integration sprint

Indicative starting point: $2,500–$10,000 for implementing authority around an existing agent/tool stack.

### Design-partner deployment

Indicative starting point: $5,000–$15,000 for a bounded organizational pilot.

### Institutional deployment

Indicative starting point: $10,000+ for self-hosted deployment, custom policy, identity integration, support, and implementation.

These are pricing hypotheses, not established market prices.

## Future control plane

A paid management layer can provide:

- agent inventory;
- policy distribution;
- approval inbox;
- revocation;
- delegated authority graph;
- authority scoring;
- evidence retention;
- organization roles;
- managed Box backends.

The open-source enforcement primitive should remain usable without the hosted control plane.
