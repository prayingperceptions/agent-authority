# v0.1 acceptance criteria

A release candidate is successful when a third party can:

1. Generate an Ed25519 Passport without a hosted service.
2. Create a task-scoped Contract referencing the agent ID.
3. Sign and verify the Contract cryptographically.
4. Evaluate an action as `allow`, `deny`, `ask`, or `simulate`.
5. Prove that an action outside the Contract is denied.
6. Delegate a strict subset of capabilities to a child agent.
7. Prove that delegation cannot escalate authority.
8. Serialize Passport and Contract as JSON according to the included schemas.
9. Run the reference example locally.
10. Implement the protocol without adopting a specific LLM, agent framework, cloud provider, or database.
