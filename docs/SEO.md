## README search strategy

Keep the first screen focused on:

1. what it is;
2. why the problem exists;
3. the one-minute install/demo;
4. Passport → Contract → Gate → Box → Ledger;
5. the Authority Score;
6. security limitations.

Do not keyword-stuff. Search engines use titles, headings, page content, links, and other signals when forming search result titles. See Google's guidance: https://developers.google.com/search/docs/appearance/title-link

## Link strategy

Earn links by publishing useful technical content around:

- agent authorization patterns;
- MCP authorization;
- delegated agents;
- capability-based security;
- human approval gates;
- agent audit receipts.

The best long-term SEO asset is a small docs site with unique pages for those concrete problems.
