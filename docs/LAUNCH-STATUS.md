# Launch Status

Status: **Developer Preview / Alpha**

## Ready

- core Passport/Contract/Gate protocol
- approval receipts and replay prevention
- revocation state store
- signed Contract and Passport helpers
- Authority Score
- Box policy-aware execution workspace
- Ledger evidence integration
- red-team regression suite
- README and launch documentation
- GitHub SEO metadata and topics checklist

## Not yet production-grade

- hardened VM/container isolation
- durable distributed revocation/replay store
- formal issuer PKI/key rotation
- fully enforced remote delegation registry

## Recommended launch wording

> Agent Authority is an open-source reference implementation for giving AI agents portable identity, bounded authority, approvals, and verifiable evidence.

Avoid claims that the project is a complete security solution or compliance certification.
